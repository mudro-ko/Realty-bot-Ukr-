# Авто-бот: AUTO.RIA + Telegram-канали

Telegram-бот, який стежить за оголошеннями про продаж авто на **AUTO.RIA** і в
публічних **Telegram-каналах** авторинку та надсилає нові, що підходять під твої фільтри.

## Запуск (Windows)

1. У [@BotFather](https://t.me/BotFather) створи **новий** бот (`/newbot`) і скопіюй токен.
   Не використовуй токен бота нерухомості, бо два боти на одному токені конфліктують.
2. Запусти `start.bat`. Під час першого запуску він створить `.venv`, встановить залежності й відкриє `.env` у Блокноті.
3. Встав токен у рядок `BOT_TOKEN=…`, збережи файл і знову запусти `start.bat`.
4. У Telegram напиши своєму новому боту `/start`. Перший, хто це зробить, стає власником.
5. Автозапуск разом із Windows вмикається через `autostart_on.bat`, вимикається через `autostart_off.bat`.

## Що вміє пошук

- **Марка/модель**: можна кілька. Популярні є кнопками, решту знайдеш, якщо напишеш назву (кирилицею теж).
- **Рік, ціна $, пробіг (тис. км), об'єм двигуна**: у форматі «від–до», наприклад `2018-2022`, `40-70к`, `до 150`.
- **Пальне, КПП, кузов, привід, область**: можна обрати кілька.
- **Стан**:
  - лише розмитнені;
  - без ДТП;
  - лише в Україні;
  - без автосалонів.
- **Ключові слова розумні**. Наприклад, `не фарбований`, `один власник`, `сервісна історія` розпізнаються в різних формулюваннях, українською й російською. Через мінус виключаєш: `-зі сша`.
- **Джерела**: AUTO.RIA та/або Telegram-канали. Список каналів можна змінювати: додати `@канал` або прибрати зайвий.
- **Лише нижче ринку**. Медіану бот рахує по тій самій моделі, року ±1, пальному й КПП. У кожній картці видно, наскільки авто дешевше чи дорожче ринку.
- **Частота**: від 15 хв до раз на місяць, є також тижневий дайджест.

## Звіт

Кнопка «📊 Звіт» формує Excel у папці `Звіти/` поруч із ботом. У ньому:
- по аркушу на кожен пошук, з гіперпосиланнями;
- аркуш «Аналітика»: медіани за моделлю й роком, графік, топ-10 найвигідніших і порівняння джерел.

## Доступ для інших

Доступ можна дати двома способами:
- `/allow +380…` — за номером телефону;
- `/access` → «Запрошення» — за посиланням.

## Файли

- `auto_bot.py` — сам бот.
- `automon/` — джерела, фільтри, ринок, архів, звіт.
- `data/` — пошуки, стан, `cars.db` (архів), `market.db` (ринок).
