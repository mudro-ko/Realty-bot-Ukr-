# Realty-bot-Ukr-
Бот для пошуку нерухомості в Україні / поиска недвижимости в Украине

## Монітор нових оголошень → Telegram (GitHub Actions)

Кожні 30 хвилин GitHub сам запускає `python -m monitor`. Скрипт перевіряє пошуки з
[`searches.yaml`](searches.yaml) і надсилає в Telegram **лише нові** оголошення.
Сервер не потрібен, Claude у роботі не бере участі, тож токени не витрачаються.

**Джерела**
- **ЛУН** (lun.ua): агрегатор, підтягує оголошення з **OLX**, rieltor.ua та інших сайтів;
- **DIM.RIA** (dom.ria.com).

Напряму OLX не опитується, бо блокує запити з хмарних серверів. Його оголошення приходять через ЛУН.

**Що вміє**
- окремі пошуки: місто, продаж / оренда / подобово, район, кімнати, ціна ($ або ₴), площа, поверх;
- стан ремонту: `needs_repair`, `needs_repair_or_cosmetic`, `renovated` (за позначками сайтів і текстом);
- стоп-слова й обов'язкові слова, «тільки власник», «без комісії»;
- прибирає дублікати: той самий об'єкт з різних сайтів приходить один раз;
- при першому запуску пошуку надсилає 10 найновіших, далі лише нові;
- якщо сайт 3 запуски поспіль не відповідає, присилає попередження.

### Налаштування

1. **Бот.** У Telegram відкрий @BotFather → `/newbot` → скопіюй токен. Можна взяти й старий токен бота.
2. **Секрет у GitHub.** Репозиторій → *Settings* → *Secrets and variables* → *Actions* →
   *New repository secret*: назва `TELEGRAM_BOT_TOKEN`, значення — токен.
3. **Напиши своєму боту `/start`.** Перший запуск сам знайде твій чат і надішле «✅ Бот підключено».
   За бажанням можна задати секрет `TELEGRAM_CHAT_ID` вручну.
4. **Пошуки.** Редагуй `searches.yaml` прямо на GitHub (іконка олівця). Щоб увімкнути пошук,
   постав `enabled: true`. Можна вставити посилання з фільтрами з сайту ЛУН у поле `lun_url`.
5. **Ручний запуск:** вкладка *Actions* → *realty-monitor* → *Run workflow*.

Стан («що вже бачили») зберігається в окремій гілці `state`. Там же лежить `last_run.json`,
звіт останнього запуску: скільки знайдено, скільки відсіяно і чому.

**Приватність.** У публічному репозиторії пошуки видно всім. Варіанти: зробити репозиторій
приватним (на безкоштовному плані 2000 хв/міс, одному запуску вистачає ~1 хв) або перенести
вміст `searches.yaml` у секрет `SEARCHES_YAML`.

## Telegram-бот v4 (кнопки, локально на Windows)

`realty_bot.py` — інтерактивний бот: пошуки створюються кнопками в Telegram, перевірка за розкладом
усередині бота, нові оголошення приходять самі. Використовує ті самі парсери, що й монітор
(ЛУН з OLX усередині + DIM.RIA). Дані зберігаються в `data/db.json`.

**Запуск на Windows**
1. Створи бота в @BotFather (`/newbot`) і скопіюй токен.
2. Подвійний клік по `start.bat`. Перший раз він створить `.venv`, поставить залежності й відкриє `.env`:
   впиши `BOT_TOKEN=...`, збережи й закрий Блокнот.
3. Напиши боту `/start`: ти стаєш власником, іншим бот відповідатиме «приватний бот».
4. ➕ **Новий пошук** або `/presets`, щоб узяти готовий пошук із `searches.yaml`.

`autostart_on.bat` запускає бот згорнутим при вході у Windows, `autostart_off.bat` вимикає автозапуск.
Бот працює, поки комп'ютер увімкнений і не спить. Лог пишеться в `data\bot.log`.

Цей бот і GitHub-монітор — альтернативи. Не запускай обидва з одним токеном.
